Maximum diversification

The diversification ratio of a portfolio is the weighted average of the volatilities of its assets, divided by the volatility of the portfolio.

\[\mathrm{DR}(\boldsymbol{w}) = \frac{\boldsymbol{w}^\intercal \boldsymbol{\sigma}}{\sqrt{\boldsymbol{w}^\intercal \mathbf{\Sigma} \boldsymbol{w}}}\,,\]

where $\boldsymbol{\sigma}$ is the vector of the volatilities of the assets and $\mathbf{\Sigma}$ is their covariance matrix. The ratio is one for a portfolio of one asset, and it grows as the correlations between the assets cut the risk of the portfolio. The maximum diversification portfolio maximises it.

The library has no optimiser of that name, and it needs none. The ratio is a MaximumRatio problem of MeanRisk:

  • the numerator is the expected return of the portfolio, when the expected return of each asset is its volatility. StandardDeviationExpectedReturns gives this vector to the prior;
  • the denominator is the StandardDeviation risk measure;
  • the risk-free rate is zero, the default of MaximumRatio.

This page builds the portfolio, checks that it has the largest diversification ratio, and compares it with the InverseVolatility and the minimum-variance portfolios.

When to reach for this

Reach for the maximum diversification portfolio when you do not trust the estimates of the expected returns, but you want more than the minimum-variance portfolio. It uses only the covariance matrix, as the minimum-variance portfolio does, but it does not prefer the assets of low volatility. It prefers the assets of low correlation to the others.

2. The maximum diversification portfolio

The return measure of MeanRisk is ArithmeticReturn by default, and it reads the mean vector of the prior. So the expected return of the portfolio is $\boldsymbol{w}^\intercal \boldsymbol{\sigma}$, and MaximumRatio with rf = 0 maximises the diversification ratio.

The risk-free rate must be zero. A rate rf other than zero maximises $(\boldsymbol{w}^\intercal \boldsymbol{\sigma} - r_f) / \sqrt{\boldsymbol{w}^\intercal \mathbf{\Sigma} \boldsymbol{w}}$, which is a different problem with a different portfolio.

The minimum-variance portfolio has the lowest volatility, and the maximum diversification portfolio does not. The two portfolios answer different questions: the first asks for the least risk, and the second asks for the most risk that the correlations remove.

5. The minimum variance of the correlation matrix

Write the weights as $w_i = y_i / \sigma_i$, up to a positive scale. The diversification ratio is then $\sum_i y_i / \sqrt{\boldsymbol{y}^\intercal \mathbf{C} \boldsymbol{y}}$, where $\mathbf{C}$ is the correlation matrix. With the budget $\sum_i y_i = 1$, to maximise the ratio is to minimise the variance $\boldsymbol{y}^\intercal \mathbf{C} \boldsymbol{y}$. So the maximum diversification portfolio is the minimum-variance portfolio of the correlation matrix, divided by the volatilities and scaled to the budget.

CorrelationCovariance returns the correlation matrix of the estimator that it wraps, so a prior with it as ce has $\mathbf{C}$ in the place of $\mathbf{\Sigma}$. We solve the minimum-variance problem on that prior, and compare the result with the portfolio of section 2.

pr_cor = prior(EmpiricalPrior(;                              ce = CorrelationCovariance(;                                                         ce = PortfolioOptimisersCovariance())),               rd)res_cor = optimise(MeanRisk(; r = r, obj = MinimumRisk(),                            opt = JuMPOptimiser(; pe = pr_cor, slv = slv)))w_cor = res_cor.w ./ pr.muw_cor ./= sum(w_cor)isapprox(w_cor, res_md.w; atol = 1e-4)

An L1UncertaintySet gives a portfolio of k assets with no binary variables. The ℓ1 uncertainty sets example shows the model. MaximumReturn with NoRisk maximises the worst-case return over the set, and the result holds the k assets with the highest characteristic, with equal weights. It is a linear program, so HiGHS solves it alone.

The set must be centred on the return term of this page, the volatilities. So its prior takes StandardDeviationExpectedReturns, as the prior of section 1 does. ActiveAssetsUncertaintyAlgorithm finds the radius that makes k assets active.

The two forms do not select the same assets. The ℓ1 set ranks the assets on its characteristic, so it holds the k assets of the highest volatility. That is not the selection that maximises the diversification ratio, so its ratio is lower than the ratio of the card portfolio. The ℓ1 set replaces the binary variables when the ranking on the characteristic is the selection that you want.

The ℓ1 set can also enter a MinimumRisk problem, through a lower bound on the worst-case return. The bound must be the largest worst-case return that the constraints let the portfolio reach. A bound slot holds a value that you give before the solve, and you know that value only after you solve the problem above. A larger bound, such as the largest volatility, makes the problem infeasible. So use the form above.
