PortfolioOptimisers.weighted_high_median! — Function
weighted_high_median!(a::AbstractVector, b::AbstractVector, m::Integer) -> Number

Returns the smallest value of the first m pairs of a at which the cumulative weight reaches half of the total weight.

Each entry of a is a pair of a value and an integer weight. The method selects the value and does not sort the pairs, so it takes $O(m)$ operations on average. The partition has no branch on the data. It writes each pair at the two ends of the other buffer, and moves only the end that the comparison with the pivot names. A branch on the data costs more than the two writes, because the processor cannot predict it.

kth_pairwise_difference uses the value as its trial value. At least half of the weight is at or below the value, and at least half of the weight is at or above it. So each trial removes at least one quarter of the candidates.

Algorithm

  1. Take all m pairs as the range. The target is half of the total weight, rounded up.
  2. While the range holds more than one pair, do these steps:
    1. Take the median of the first, the middle and the last value of the range as the pivot.
    2. Copy the pairs below the pivot to the start of the same range of the other buffer, and the pairs above it to the end. Add the weight of each group.
    3. If the weight below the pivot reaches the target, keep the pairs below it. If the weight at or below the pivot reaches the target, return the pivot. Otherwise, subtract that weight from the target, and keep the pairs above the pivot.
    4. Swap the two buffers.
  3. Return the value that is left.

Arguments

  • a: The pairs of a value and a positive integer weight. The method overwrites it.
  • b: A buffer of the same element type and of length m or more. The method overwrites it.
  • m: The number of pairs, 1 <= m <= length(a).

Returns

  • t::Number: The weighted high median, one of the values of a.

PortfolioOptimisers.count_pairs_below! — Function
count_pairs_below!(P::Vector{Int}, y::VecNum, t::Number, cmp) -> Int

Counts, for each row i of the sorted vector y, the differences y[j] - y[i] with j > i for which cmp(y[j] - y[i], t) holds.

The differences of one row grow with j, so the count of a row is the position of the first difference that fails the test. The difference y[j] - y[i] falls when i grows, so that position never moves back. One pass over the rows finds every count.

Arguments

  • P: The output vector, of the length of y. Entry i gets the count of row i.
  • y: The data, sorted in increasing order.
  • t: The trial value.
  • cmp: < to count the differences below t, or <= to count the differences at or below t.

Returns

  • s::Int: The sum of the counts.

PortfolioOptimisers.kth_pairwise_difference — Function
kth_pairwise_difference(y::VecNum, k::Integer) -> Number

Returns the k-th smallest of the differences y[j] - y[i], i < j, of a sorted vector.

The method selects the order statistic in $O(n \log n)$ operations and does not form the $n(n-1)/2$ differences. The differences of each row i are sorted in j. The method keeps, for each row, the number of differences that are below its range of candidates, and the number that are at or before the end of that range. These are the counts of earlier steps, so a step that narrows the ranges swaps two vectors. Each step takes the median candidate of each row, and gives it the weight of the size of its range. The weighted high median of these candidates is the trial value, see weighted_high_median!. The method then counts the differences below the trial value, and the differences at or below it, with count_pairs_below!. The answer is the trial value, or it is in the ranges below or above it. Each step removes at least one quarter of the candidates. When at most n candidates remain, the method selects the answer among them.

qn_scale uses it for the order statistic of the scale estimator $Q_n$.

Algorithm

  1. Set the candidates of row i to all its n - i differences.
  2. While more than n candidates remain, do these steps:
    1. Find the trial value from the median candidates of the rows that are not empty, with pairwise_trial_value!.
    2. Count the differences below the trial value. If k is at most this count, the count of each row is the new end of its range. Go to the next step of the loop.
    3. Count the differences at or below the trial value. If k is at most this count, return the trial value. Otherwise, the count of each row is the new number below its range.
  3. Collect the candidates. Subtract the number of differences below the ranges from k, and select the remaining rank with partialsort!.

Arguments

  • y: The data, sorted in increasing order.
  • k: The rank, 1 <= k <= n * (n - 1) ÷ 2.

Returns

  • q::Number: The k-th smallest pairwise difference.

qn_finite_factor(n::Integer) -> Number

Returns the finite-sample factor of the scale estimator $Q_n$ at n observations.

qn_scale multiplies the order statistic by the asymptotic constant and by this factor, so that the scale is unbiased at the normal model for a small sample. The values are those of the R package robustbase, version 0.99-7. For $n \leq 12$ they come from a table of simulated factors. For a larger $n$ the factor is the reciprocal of a fitted polynomial in $1/n$, with one polynomial for an odd $n$ and one for an even $n$.

PortfolioOptimisers.qn_scale — Function
qn_scale(x::VecNum) -> Number

Returns the scale estimator $Q_n$ of [241] of a vector.

$Q_n$ is the $k$-th order statistic of the absolute pairwise differences of the data, with $k = \binom{h}{2}$ and $h = \lfloor n/2 \rfloor + 1$. Its breakdown point is one half, and its efficiency at the normal model is 82 %. It does not need a location estimate. DetMCD standardises each column of the data by its median and by this scale.

Mathematical definition

\[\begin{align} Q_n &= d_n \, c \, \left\lbrace |x_i - x_j| \,;\, i < j \right\rbrace_{(k)}\,. \end{align}\]

Where:

  • $c = 2.21914$: The constant that makes the estimator consistent at the normal model, $1/(\sqrt{2}\,\Phi^{-1}(5/8))$ to six digits.
  • $d_n$: The finite-sample factor of qn_finite_factor.
  • $\lbrace \cdot \rbrace_{(k)}$: The $k$-th order statistic.

Algorithm

  1. Return zero when x holds fewer than two values.
  2. Sort x, and select the k-th pairwise difference with kth_pairwise_difference.
  3. Multiply the result by the constant and by the factor of qn_finite_factor.

Arguments

  • x: The data.

Returns

  • s::Number: The scale, of the element type of x.

PortfolioOptimisers.quantile_scale — Function
quantile_scale(z::VecNum, w::Option{<:StatsBase.AbstractWeights}) -> Number

Returns the scale of a normal distribution that has the first positive quantile of the absolute values of z, or zero.

The function follows the rule of the R package robustbase, version 0.99-7, for a column whose $Q_n$ is zero. It reads the quantiles at the probabilities $0.5, 0.55, \ldots, 0.95$ and $0.9875$. It takes the first quantile $q_a$ that is not zero, and returns $q_a / \Phi^{-1}((a + 1)/2)$. The quantile at $0.5$ is the median, so the scale is the median absolute deviation when at most half of the values are at the centre. When every quantile is zero, almost every value is at the centre, and the column has no robust scale. The function then returns zero.

Arguments

  • z: The values, centred by their median or by a fixed centre.
  • w: The observation weights, or nothing.

Returns

  • s::Number: The scale, of the element type of z. It is zero when every quantile is zero.

robust_column_scale(z::VecNum) -> Number
