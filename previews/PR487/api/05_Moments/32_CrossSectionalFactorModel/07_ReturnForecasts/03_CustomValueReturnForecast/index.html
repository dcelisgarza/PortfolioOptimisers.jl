Custom Value Return Forecast

Types

PortfolioOptimisers.CustomValueReturnForecast — Type
struct CustomValueReturnForecast{__T_mu} <: AbstractReturnForecastEstimator

A Return Forecast the caller states outright.

The member fits nothing. It carries the forecast the caller wrote, one entry per asset of the coverage universe and in return units, and return_forecast checks it against the block and hands it back. It is the stated member of its family, as CustomValueExpectedReturns is of the expected returns family and ConstantExposure is of the Factor Exposure family, and a caller uses it to carry a forecast another tool produced through the prior's split.

An asset the caller forecasts nothing for carries a NaN, which is how every member of the family says the same thing.

Fields

  • mu::Any: The stated Return Forecast, one entry per asset of the coverage universe, in return units, NaN where the caller forecasts nothing.

PortfolioOptimisers.CustomValueReturnForecastResult — Type
struct CustomValueReturnForecastResult{__T_mu, __T_hist} <: AbstractReturnForecastResult

Result type produced by CustomValueReturnForecast.

The member states its forecast and computes none, so hist is nothing: there is no history behind a stated vector. The two fields are the two reads AbstractReturnForecastResult states.

Fields

  • mu::Any: The latest Return Forecast, one entry per asset of the coverage universe, in return units, NaN for an asset the member forecasts nothing for.
  • hist::Any: Return Forecast history observations × assets, in return units, or nothing for a member that computes none.

PortfolioOptimisers.return_forecast — Method
return_forecast(rfe::CustomValueReturnForecast, rd::ReturnsResult,
                csfm::CrossSectionalFactorModel) -> CustomValueReturnForecastResult

Return the Return Forecast a caller stated.

Algorithm

  1. Check the stated forecast against the asset count of the block.
  2. Carry it onto the member's own Result, with no history.

The carrier is not read: the member reads no Panel Field and fits nothing.

Arguments

  • rfe: Stated Return Forecast Estimator.
  • rd: The returns result to use.
  • csfm: The fitted factor-model block, read for its asset count alone.

Validation

  • length(rfe.mu) matches the asset count of csfm. Raises a DimensionMismatch.

Returns

  • rf::CustomValueReturnForecastResult: The stated forecast.

Examples

julia> csfm = CrossSectionalFactorModel(; M = reshape([1.0, 1.0], 2, 1), b = [0.0, 0.0]);julia> rd = ReturnsResult(; nx = ["A", "B"], X = zeros(2, 2));julia> rf = return_forecast(CustomValueReturnForecast(; mu = [0.01, NaN]), rd, csfm);julia> rf.mu2-element Vector{Float64}:   0.01 NaN

PortfolioOptimisers.port_opt_view — Method
port_opt_view(rf::CustomValueReturnForecastResult, i, args...)

Return a view of a CustomValueReturnForecastResult, selecting only the assets indexed by i.

The member computes no history, so mu is the one field the view cuts.

Arguments

  • rf: A stated Return Forecast result.
  • i: Indices of the assets to select.
  • args...: Additional positional arguments (ignored).

Returns

  • rf::CustomValueReturnForecastResult: A new result whose forecast is restricted to the selected assets.
