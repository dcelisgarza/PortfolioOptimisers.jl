Every other AbstractUncertaintySetEstimator holds its own prior estimator pe and fits it on the returns that the caller gives it. So the set that it builds does not know the prior of the optimiser. PortfolioOptimisers.AbstractCompactRadiusAlgorithm — Type
abstract type AbstractCompactRadiusAlgorithm <: AbstractAlgorithm

Computes the radius $\kappa$ of a compact covariance uncertainty set from the Prior Result and the geometry of the set.

The radius of a CompactCovarianceUncertaintySet then changes when the sample or the factor span changes. A member goes in the kappa field of an OrthogonalUncertaintySet, whose type bound is Num_CptRad. A plain number in that field is the radius, and k_compact returns it unchanged.

This family is separate from the Calibration Rules, and the two do not mix. A Calibration Rule reads (pr, w, slv, ctx) and nothing more. These four inputs cannot size the compact radius, because its units change with a different field of the same estimator. The penalty is $\kappa \lVert (\mathbf{I} - \mathbf{Q}\mathbf{Q}^{\intercal})\mathbf{C}\boldsymbol{w} \rVert_{2}^{2}$ with $\mathbf{C} = \mathbf{W}^{-1/2}$. Under metric = nothing, $\kappa$ has the units of a variance. Under InverseIdiosyncraticVarianceMetric, it has no units.

A rule that reads only the Prior Result must select one of the two units, and it is wrong under the other. So a rule of this family computes the radius inside the family, which has the metric, the loadings block and the span. The mean radius of the same estimator follows the same pattern through k_norm_ball and the method field. A field that holds a radius also accepts the rule that computes it.

The name of a rule is the name of the method that it runs, and no other part of the library uses either word. ResidualInflation increases the residual variance to a confidence bound. VarianceFraction sets the penalty to a fraction of the nominal variance at a reference portfolio.

struct BoxUncertaintySet{__T_lb, __T_ub, __T_val} <: AbstractUncertaintySetResult

Holds the element-wise lower and upper bounds of a box uncertainty set on a mean vector or on a covariance matrix.

A box is a convex polytope, so it is a polyhedral confidence interval on the entries that it bounds. Section 3.1 of [161] states the worst case on the mean axis, $\hat{\boldsymbol{\mu}}^{\intercal} \boldsymbol{w} - \delta^{\intercal} \lvert \boldsymbol{w} \rvert$ for a box symmetric about $\hat{\boldsymbol{\mu}}$. Section 5.2.6 of the same work states the worst case on the covariance axis as Equation 7. Equation 7 is the dual of the semidefinite programme of Equation 6. Its constraint $\mathbf{Z} + \mathbf{\Lambda}_u - \mathbf{\Lambda}_l = -\boldsymbol{w} \boldsymbol{w}^\intercal$ has the wrong sign: the dual of the worst case needs $\mathbf{\Lambda}_u - \mathbf{\Lambda}_l \succeq \boldsymbol{w} \boldsymbol{w}^\intercal$.

The two axes read the bounds differently, so a set fitted for one axis is not a set for the other. On the mean axis, set_ucs_return_constraints! reads only the half-width $(\boldsymbol{u} - \boldsymbol{\ell}) / 2$ of the bounds, which is the $\delta$ of the definition below. It centres that width on val. So neither lb nor ub is a bound on the mean alone. This is why two estimators can write one set in two ways and agree. ARCHUncertaintySet stores the two quantiles of the bootstrap mean. DeltaUncertaintySet and the normal box write $\boldsymbol{\ell} = \boldsymbol{0}$ and put the full width in $\boldsymbol{u}$.

On the covariance axis, set_ucs_variance_risk! reads $\operatorname{tr}(\mathbf{A}_{u} \mathbf{\Sigma}_{u}) - \operatorname{tr}(\mathbf{A}_{l} \mathbf{\Sigma}_{l})$ under $\mathbf{A}_{u} - \mathbf{A}_{l} = \mathbf{W}$. So each bound binds alone, and the covariance box is absolute. That route has no centre, so it never reads val.

Mathematical definition

\[\begin{align} U^{\text{box}}_{\boldsymbol{\mu}} &= \left\{ \boldsymbol{\mu}\, \vert\, \lvert \boldsymbol{\mu} - \boldsymbol{\hat{\mu}} \rvert \leq \delta \right\} \\ U^{\text{box}}_{\mathbf{\Sigma}} &= \left\{ \mathbf{\Sigma}\, \vert\, \mathbf{\Sigma}_{l} \leq \mathbf{\Sigma} \leq \mathbf{\Sigma}_{u},\, \mathbf{\Sigma} \succeq 0 \right\}\,. \end{align}\]

Where:

  • $U^{\text{box}}_{\boldsymbol{\mu}}$: Box uncertainty set for expected returns.
  • $U^{\text{box}}_{\mathbf{\Sigma}}$: Box uncertainty set for the covariance matrix.
  • $\boldsymbol{\mu}$, $\mathbf{\Sigma}$: Uncertain expected returns and covariance.
  • $\boldsymbol{\hat{\mu}}$: Estimated mean vector, the centre of the box.
  • $\delta$: Element-wise half-width of the box.
  • $\mathbf{\Sigma}_{l}$, $\mathbf{\Sigma}_{u}$: Lower and upper bounds of the covariance matrix.
  • $\mathbf{\Sigma} \succeq 0$: Constraint that the matrix is positive semidefinite.

Fields

  • lb: Lower bound.
  • ub: Upper bound.
  • val: Quantity that the set is a neighbourhood of. It is a vector on the mean axis and a covariance matrix on the covariance axis. nothing lets the consumer use its own quantity. A value has priority over the field of the returns estimator and over the prior.

Constructors

BoxUncertaintySet(;    lb::ArrNum,    ub::ArrNum,    val::Option{<:ArrNum} = nothing) -> BoxUncertaintySet

The keywords are the fields of the struct.

Validation

  • !isempty(lb).
  • !isempty(ub).
  • size(lb) == size(ub).
  • If val is an array, size(val) == size(lb).

PortfolioOptimisers.NormalKUncertaintyAlgorithm — Type
struct NormalKUncertaintyAlgorithm{__T_kwargs} <: AbstractUncertaintyKAlgorithm

Computes the radius k of the ellipsoid from a sample, as the 1 - q quantile of the Mahalanobis distances of the sampled estimation errors.

The algorithm makes no assumption about the distribution. It reads the errors that the estimator sampled, from a parametric draw or from a bootstrap resample. ChiSqKUncertaintyAlgorithm and GeneralKUncertaintyAlgorithm give the radius in closed form.

The sample must be the estimation error, not the estimate. When the errors are normal, the squared Mahalanobis distance of a centred error has a chi-squared distribution. So this algorithm and ChiSqKUncertaintyAlgorithm compute one radius in two ways, and they agree to within the noise of the sample. That radius depends only on the dimension and the significance level. A sample of the raw estimates makes the distance non-central. The radius then increases with the non-centrality $T \hat{\boldsymbol{\mu}}^{\intercal} \hat{\mathbf{\Sigma}}^{-1} \hat{\boldsymbol{\mu}}$, although it must measure only the estimation error.

The algorithm measures the distances against the shape matrix that it gets, not against the first shape of the estimator. ellipsoidal_set replaces the asymptotic covariance with its diagonal before it calls k_ucs. So under the default diagonal = true, the radius is a quantile of the distances against the diagonal shape. The two radii are different, and neither shape always gives the larger radius.

Mathematical definition

\[k = \sqrt{Q_{1-q}\!\left(\left\{ \boldsymbol{\delta}^{(m)\intercal} \mathbf{\Sigma}_{\boldsymbol{\delta}}^{-1} \boldsymbol{\delta}^{(m)} \right\}_{m=1}^{M}\right)}\,.\]

Where:

  • $\boldsymbol{\delta}^{(m)}$: The $m$-th sampled estimation error, a row of the X argument of k_ucs.
  • $\mathbf{\Sigma}_{\boldsymbol{\delta}}$: Shape matrix of the ellipsoid.
  • $Q_{1-q}$: The 1 - q quantile function.
  • $M$: Number of samples.

PortfolioOptimisers.GeneralKUncertaintyAlgorithm — Type
struct GeneralKUncertaintyAlgorithm <: AbstractUncertaintyKAlgorithm

Computes the radius k of the ellipsoid as sqrt((1 - q) / q), a closed form that holds for every distribution of the estimation errors.

The radius is the factor $\kappa(\epsilon)$ of Theorem 1 of [162], Equation 8, at $\epsilon = q$. It reads neither the data nor the shape matrix. The theorem bounds the worst-case value at risk over every distribution with a given mean and covariance. The radius comes from the one-sided Chebyshev inequality of Cantelli. So it holds for every distribution of the estimation errors that has the stated second moment. When the errors are normal, use ChiSqKUncertaintyAlgorithm, because its radius is smaller there.

The guarantee is a bound in one direction, not a joint region for the full vector. It covers the scalar that a robust row bounds, which is the worst-case value of $\boldsymbol{w}^{\intercal} \boldsymbol{\mu}$ at the weights that the model selects. It holds with a probability of at least $1 - q$. The chi-squared radius gives a joint confidence region for all entries together.

Mathematical definition

\[k = \sqrt{\dfrac{1 - q}{q}}\,.\]

Where:

  • $q$: Significance level.

The inverse of the form is $\left(1 + k^{2}\right)^{-1} = q$, which is the bound of Cantelli at $k$ standard deviations. So the radius is the smallest radius whose tail bound is $q$ for every distribution with the stated moments.

PortfolioOptimisers.ChiSqKUncertaintyAlgorithm — Type
struct ChiSqKUncertaintyAlgorithm{__T_ambient} <: AbstractUncertaintyKAlgorithm

Computes the radius k of the ellipsoid as the square root of a chi-squared quantile, a closed form for normal estimation errors.

The degrees of freedom are the dimension of the set, which is the number of free coordinates of the estimation error. On the mean axis, the dimension is $N$. On the covariance axis, the error is a vectorised symmetric $N \times N$ matrix. The entries $(i, j)$ and $(j, i)$ are one number, so the error has $N(N+1)/2$ free coordinates of the $N^{2}$. The shape of the normal method, $\left(\mathbf{I} + \mathbf{K}\right) \left(\mathbf{\Sigma} \otimes \mathbf{\Sigma}\right) / T$, has that rank. Theorem 3.1 (vi) of [163] gives $\mathbf{K}$ the eigenvalue $+1$ with multiplicity $N(N+1)/2$.

The squared Mahalanobis distance of a normal error has a chi-squared distribution at the rank of its shape. So a full covariance shape reads $N(N+1)/2$. A diagonal shape reads $N^{2}$, because its statistic is a sum of $N^{2}$ terms with a mean of one. ucs_dimension states the rule, and the set builders give its value to k_ucs and k_norm_ball.

ambient = true reads the dimension of the ambient space instead. That is the first dimension of the shape matrix or of the geometry map, which is $N^{2}$ on every covariance shape. At $N = 5$ and $q = 0.05$, that radius is $6.136$, and the dimension of the set gives $5.000$. So the set covers $0.999$ of the errors, not $0.95$, and the radius is too large for its level. As $N$ increases, the ratio of the two radii decreases to $1 / \sqrt{2}$. The field keeps that rule available for a comparison with a caller that counts every entry of the vectorised matrix.

The sources state this closed form for the mean axis only. Equation 50 of [164] states that the squared Mahalanobis distance of a normal estimation error has a chi-squared distribution at the dimension of the estimate. That work sizes its sets with an F quantile, because it estimates the variance. Equation 11.23 of [11] sets $\kappa^{2}_{\boldsymbol{\mu}}$ to the chi-squared quantile at $n$ degrees of freedom, where $n$ is the number of assets. It gets $\kappa^{2}_{\mathbf{\Sigma}}$ from a simulation, not in closed form. The form on the covariance axis is an extension that this library makes.

Section 4.1 of [161] bounds the $N(N+1)/2$ distinct entries of the covariance with its ellipsoid, and the dimension of the set reads that count. NormalKUncertaintyAlgorithm on the same errors gives the radius from the sample, and the two radii agree to within the noise of the simulation.

Mathematical definition

\[\begin{align} k &= \sqrt{\chi^{2,\,-1}_{p}(1 - q)}\,. \end{align}\]

Where:

  • $\chi^{2,\,-1}_{p}$: Inverse cumulative distribution function of the chi-squared distribution with $p$ degrees of freedom.
  • $p$: Degrees of freedom, the dimension of the set, or the first dimension of the shape matrix under ambient = true.
  • $q$: Significance level.

Fields

  • ambient: Whether the degrees of freedom are the first dimension of the shape matrix, and not the dimension of the set. The first dimension is $N^{2}$ on every covariance shape. The default is false.

PortfolioOptimisers.EllipsoidalUncertaintySet — Type
struct EllipsoidalUncertaintySet{__T_sigma, __T_k, __T_class, __T_val} <: AbstractUncertaintySetResult

Holds the shape matrix, the radius, and the axis tag of an ellipsoidal uncertainty set on a mean vector or on a covariance matrix.

An ellipsoid is a Mahalanobis ball, so it is a confidence region that holds the correlation between the entries that it bounds. Section 3.2 of [161] states the set and its worst case on the mean axis. Section 4.1 of the same work bounds the distinct entries of the covariance with an ellipsoid. Equation 6.12 of [52] states that set again on $\text{vec}(\mathbf{\Sigma})$, and Equations 6.13 to 6.15 state its worst case. The two worst cases are second-order cones.

class names the axis, and the axis sets the size of sigma and the index that a view applies. A set with MuUncertaintySetClass has an $N \times N$ shape matrix and takes the plain asset index. A set with SigmaUncertaintySetClass has an $N^{2} \times N^{2}$ shape matrix, because it bounds a vectorised covariance. So port_opt_view finds $N$ from the shape matrix, and maps the asset index through fourth_moment_index_generator before it slices. The two consumers also dispatch on the tag, and the builder of the robust return refuses a set with the covariance tag.

A view keeps k unchanged, so it is not the set that the same estimator fits on the subset alone. When the shape is diagonal, the restricted shape matrix is equal to the shape matrix fitted on the subset, entry for entry. The radius is not equal, because two of the three algorithms calibrate it on the dimension or on the sample. Only GeneralKUncertaintyAlgorithm gives the same radius, because it reads neither the data nor the shape. So a view is the conservative choice. A caller who needs the radius of the subset fits the subset.

Mathematical definition

\[\begin{align} U^{\text{ellip}}_{\boldsymbol{\mu}} &= \left\{ \boldsymbol{\mu}\, \vert\, \left( \boldsymbol{\mu} - \boldsymbol{\hat{\mu}} \right)^{\intercal} \mathbf{\Sigma}^{-1}_{\boldsymbol{\mu}} \left( \boldsymbol{\mu} - \boldsymbol{\hat{\mu}} \right) \leq k^{2}_{\boldsymbol{\mu}} \right\} \\ U^{\text{ellip}}_{\mathbf{\Sigma}} &= \left\{ \mathbf{\Sigma}\, \vert\, \left( \text{vec}\left(\mathbf{\Sigma}\right) - \text{vec}\left(\mathbf{\hat{\Sigma}} \right) \right)^{\intercal} \mathbf{\Sigma}^{-1}_{\mathbf{\Sigma}} \left( \text{vec}\left(\mathbf{\Sigma}\right) - \text{vec}\left(\mathbf{\hat{\Sigma}} \right) \right) \leq k^{2}_{\mathbf{\Sigma}},\, \mathbf{\Sigma} \succeq 0 \right\}\,. \end{align}\]

Where:

  • $U^{\text{ellip}}_{\boldsymbol{\mu}}$: Ellipsoidal uncertainty set for expected returns.
  • $U^{\text{ellip}}_{\mathbf{\Sigma}}$: Ellipsoidal uncertainty set for the covariance matrix.
  • $\boldsymbol{\mu}$, $\mathbf{\Sigma}$: Uncertain expected returns and covariance.
  • $\boldsymbol{\hat{\mu}}$, $\mathbf{\hat{\Sigma}}$: Estimated mean and covariance, the centres of the two sets.
  • $\mathbf{\Sigma}_{\boldsymbol{\mu}}$: Covariance matrix of the estimation error of the mean.
  • $\mathbf{\Sigma}_{\mathbf{\Sigma}}$: Covariance matrix of the estimation error of the vectorised covariance.
  • $k^{2}_{\boldsymbol{\mu}}$, $k^{2}_{\mathbf{\Sigma}}$: Squared radii of the two ellipsoids.
  • $\text{vec}(\cdot)$: Vectorisation operator, which stacks the columns.
  • $\mathbf{\Sigma} \succeq 0$: Constraint that the matrix is positive semidefinite.

Fields

  • sigma: Shape matrix of the ellipsoid, which the estimator derives from the covariance of the estimation error. It is $N \times N$ on the mean axis and $N^{2} \times N^{2}$ on the covariance axis.
  • k: Radius of the ellipsoid. It must be positive.
  • class: Axis tag of the set, which sets the row count of the shape matrix or of the geometry map.
  • val: Quantity that the set is a neighbourhood of. It is a vector on the mean axis and a covariance matrix on the covariance axis. nothing lets the consumer use its own quantity. A value has priority over the field of the returns estimator and over the prior.

The radius from a simulated sample is the method that Section 11.3.2 of [11] describes. A plain Number in place of an algorithm is the radius.

Algorithm

Each of the first three methods does one procedure. The fourth method, k_ucs(type::Number, args...), returns its argument and does no step, so it has no numbered steps below.

NormalKUncertaintyAlgorithm:

  1. Compute k_mus = LinearAlgebra.diag(X * (sigma_X \ transpose(X))), the squared Mahalanobis distance of each row of X against the shape matrix. The method does the solve one time for the full sample, not one row at a time.
  2. Take the 1 - q quantile of k_mus with the keywords km.kwargs, and return its square root as the radius.

GeneralKUncertaintyAlgorithm:

  1. Return sqrt((one(q) - q) / q) as the radius. The method reads neither X nor sigma_X, so args... takes the two of them.

ChiSqKUncertaintyAlgorithm:

  1. Read the degrees of freedom from df, the dimension of the set. If km.ambient is true, read them from size(sigma_X, 1).
  2. Return the square root of the 1 - q chi-squared quantile at those degrees of freedom as the radius. The method runs no simulation, so it ignores the sample argument.

Arguments

  • km: Radius algorithm.
  • q: Significance level.
  • X: Matrix of estimation errors, with one row for each sample. Every caller gives centred deviations, not levels. Each row is a deviation from the point estimate, and the method cannot check it. A sample that is not centred makes the distance non-central, and makes the radius too large.
  • sigma_X: Shape matrix of the ellipsoid, against which the method measures the distances. It is $N \times N$ on the mean axis and $N^{2} \times N^{2}$ on the covariance axis. Under its default diagonal = true, ellipsoidal_set gives the diagonal of the asymptotic covariance. So the method takes the quantile against that diagonal, not against the full matrix.
  • df: Dimension of the set, which ucs_dimension gives. The default size(sigma_X, 1) is correct on a shape of full rank. It is too large on a full covariance shape, whose rank is $N(N+1)/2$, so ellipsoidal_set always gives df. NormalKUncertaintyAlgorithm ignores it, because its sampled distances contain the dimension.
  • args...: More arguments, which the algorithms that need no sample ignore.
  • type: The radius as a number.

Returns

  • k::Number: Radius of the ellipsoid.
