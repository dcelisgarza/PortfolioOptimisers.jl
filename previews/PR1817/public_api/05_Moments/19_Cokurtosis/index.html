struct Cokurtosis{__T_me, __T_mp, __T_alg, __T_w, __T_cvg, __T_cache} <: CokurtosisEstimator

Estimates the square cokurtosis matrix of a returns matrix.

Cokurtosis holds a mean estimator, a matrix processing estimator and a moment algorithm. cokurtosis returns one assets² × assets² matrix. That matrix is the stacked fourth comoment $\mathbf{\Sigma}_{4}$ of Section 2 of [66] and not the assets × assets³ tensor $\mathbf{M}_{4}$ of Section 2.3 of [64].

Fields

  • me: Expected returns estimator.
  • mp: Matrix processing estimator.
  • alg: Moment algorithm.
  • w: Optional observation weights vector observations × 1, or a concrete subtype of DynamicAbstractWeights. If nothing, the computation is unweighted.
  • cvg: Optional CoveragePolicy. nothing selects the reduce-and-expand path of the Coverage Universe. On that path, an asset that is not finite or not active at an observation of the window is NaN in all of the result. A policy replaces that path with available-case estimation. The fit of each cell reads the observations at which all the assets of that cell are finite and active, and each cell has its own denominator. An asset is in the result where admits admits it.
  • cache: Optional partial-fit state. It is nothing until partial_fit! writes one. When the caller gives no data matrix, the batch verb of the estimator reads it. Each propagation channel does one thing with it. factory keeps it unchanged, because a factory call resolves the configuration, not the sample. port_opt_view copies the entries of the selected assets into a new state, so the viewed estimator holds the state of those assets alone. obs_weights_view removes it, because a state has no slice on the observation axis. Only a type with an observation-weights field has that channel. A type with no such field falls through to the identity method, so it keeps its state. A family whose state has no exact asset slice removes it on both axes and names the reason.

PortfolioOptimisers.cokurtosis — Function
cokurtosis(kte::Option{<:Cokurtosis}, X::MatNum; dims::Int = 1,
           mean = nothing, kwargs...)

Computes the square cokurtosis matrix of a dataset.

The method centres the data with kte.me, and it repairs the result with kte.mp. It applies the observation weights of kte.w when they are set. FullMoment takes the centred returns, and SemiMoment clips every positive deviation to zero. When the estimator is nothing, the method returns nothing.

kte.w weights the whole estimate, so it applies to the centre and to the deviations. When mean is nothing and kte.w is not, the method sends kte.me through factory with kte.w. So kte.w replaces the weights that kte.me holds. Pass mean for a centre that kte.w does not describe.

Algorithm

The type of kte.cvg selects the method, so no branch reads the value of the policy. coverage_covariance selects the arm of a covariance in the same way.

When kte.cvg is nothing, the method takes the Coverage Universe arm. It centres the whole window on one vector. The FullMoment and the SemiMoment methods differ only in step 5.

  1. Orient X to observations × assets with dims_oriented, which validates dims.
  2. Refuse an inactive cell of active_mask with assert_finite_sample, because a plain estimator reads that cell as a non-finite return.
  3. Resolve the observation weights w from kte.w with get_observation_weights.
  4. Resolve the centre mu from kte.me and kte.w with weighted_centre, which reads mean when the caller gave one.
  5. Replace X with the deviation matrix. FullMoment takes X .- mu, and SemiMoment takes min.(X .- mu, 0).
  6. Delegate to _cokurtosis with the deviation matrix, kte.mp and w, and return the matrix it returns.

When kte.cvg is a CoveragePolicy, the method takes the available-case arm. It fits each quadruple on the observations at which its four assets are all finite and active, so each cell has its own denominator. The centre of each asset is the available-case mean of that asset, over its own finite and active observations. It is not a mean over the observations of the quadruple. coskewness states the reason, and the arm refuses an external mean for the same reason.

The repair reads the block alone. matrix_processing_block! finds the block from the diagonal of the matrix. The diagonal entry at the pair (i, j) is E[yᵢ²yⱼ²], and it is finite if and only if the pair shares an observation. So the block is the set of pairs that the fit gives a value for, and the repair does not change the cells outside it.

Neither an available-case cokurtosis nor an available-case coskewness folds. An exact recursion for each cell needs the second and the third comoments over the observations of each quadruple. So the online form of an available-case cokurtosis refits a buffer through Online.

  1. Get the valid entries, the deviations from the available-case centre of each asset, and the mask of the admitted assets with coverage_comoment_block.
  2. Take the numerator as transpose(z) * z and the denominator as transpose(zc) * zc. z and zc are the pairwise expansions of the zeroed deviations and of the valid mask.
  3. Divide with coverage_divide, and frame the refused assets down both pair axes with coverage_refuse_comoment!.
  4. Repair the block with matrix_processing_block!.

When kte.w holds observation weights as well, the available-case arm makes one weighted pass, because the weights describe the whole sample.

  1. Read the deviations, the valid entries and the admitted assets with weighted_comoment_block.
  2. Build the fourth co-moment with weighted_comoment, and reshape it to N² × N².
  3. Frame the refused assets with coverage_refuse_comoment!, and repair the block with matrix_processing_block!.

Arguments

  • kte: The cokurtosis estimator.

    • kte.alg::FullMoment: The FullMoment moment algorithm gives the cokurtosis.
    • kte.alg::SemiMoment: The SemiMoment moment algorithm gives the downside cokurtosis.
    • kte::Nothing: The method returns nothing.

  • X: The data matrix (observations × assets).

  • dims: Dimension along which the computation runs.

  • mean: The optional mean vector. When it is nothing, the method computes the centre with kte.me and kte.w. The available-case arm refuses a mean vector.

  • active_mask: The active mask of the Asset Panel over the window, or nothing. The Coverage Universe arm refuses an inactive cell, as it refuses a non-finite return. The available-case arm leaves the cell out of each comoment of its asset.

  • kwargs...: More keyword arguments. When kte.cvg is nothing, the method passes them to get_observation_weights and to weighted_centre. The available-case arm ignores them.

Validation

  • dims is either 1 or 2.

Returns

  • ckurt::MatNum: Square cokurtosis matrix assets² x assets².

Examples

cokurtosis(
    kte::Cokurtosis{<:Any, <:Any, <:FullMoment},
    state::CokurtosisPartialFitState
) -> Any

Reads the square cokurtosis matrix out of a partial-fit state.

The method of cokurtosis that makes the estimate from a Partial Fit State. It returns the matrix the batch method returns, to machine precision, for the sample the state was fitted on.

Only the shape of that sample survives a partial fit, so the matrix processing estimator is handed a matrix of the right shape whose entries are zero. Of the shipped steps only :dn reads it, and it reads only size(X), so the two routes agree. A custom :alg step that reads the values of the sample must be run from the batch verb.

Algorithm

  1. Refuse a configuration the state no longer matches, with assert_partial_fittable. factory carries the state and replaces w, so an estimator that says weighted may hold a state fitted unweighted. The state stays on the estimator, so a caller who restores w = nothing reads it again.
  2. Divide the fourth accumulator by the observation count, giving the cokurtosis matrix.
  3. Process it in place through matrix_processing_block!, under kte.mp and the shape of the fitted sample. It is the block arm rather than the plain one for the reason the low order's cov(ce) with no data takes it: a plain fold over a changing universe answers NaN for an asset outside the Coverage Universe at every pair naming it, and a positive-definite repair over that frame meets a LAPACK refusal rather than a named error. The block arm repairs the finite block and leaves the frame for investable_mask to read, which is what the batch verb's reduce-and-expand leaves it too; a complete matrix runs the plain arm over the whole of it.

Arguments

  • kte: Cokurtosis estimator with a FullMoment moment algorithm.
  • state: Partial-fit state written by partial_fit!.

Validation

  • kte.w is nothing and kte.me is an unweighted SimpleExpectedReturns. An ArgumentError is thrown otherwise.

Returns

  • ckurt::MatNum: Square cokurtosis matrix assets² x assets².

Reads a cokurtosis matrix out of a SampleBufferState, by running the batch verb over the observations the buffer holds.

The method of cokurtosis that makes the estimate from a Sample Buffer. An estimator wrapped in Online carries a buffer rather than a family state, so it takes no exact fold, and its estimate is whatever a batch fit over the rows the buffer holds gives — every observation folded so far when the buffer is uncapped, and the last max_history of them when it is capped. It runs no assert_partial_fittable check of its own: the batch verb answers configurations an incremental fold cannot, and a wrapper is how a caller reaches them. The buffer also holds the per-observation masks it was folded with, so the batch verb is given the mask that explains the rows and a wrapped estimator under a CoveragePolicy answers what an unwrapped one answers.

The call with no data, cokurtosis(kte), fills state with the state that the estimator carries, which partial_fit_cache reads out of the cache field. The call then goes to the method of cokurtosis for the type of that state, as the call with no data of coskewness does. The default serves the estimators that fold by buffering alone, such as WindowedCokurtosis.

Arguments

  • kte: Cokurtosis estimator.
  • state: The buffer to read. The default is the state that kte carries.

Validation

  • With no state, the estimator carries a state. An ArgumentError is thrown otherwise.

Returns

  • ckurt::MatNum: Cokurtosis matrix of the observations the buffer holds.
