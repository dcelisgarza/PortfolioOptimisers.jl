Prior Returns Source: private API

Each reader of the returns states its own source in its x_src field. A prior reads the returns data in the source that it states. A clustering, phylogeny or centrality estimator reads a prior result or the returns data, and the picker below gives it the matrix of its source. A fit finds the gaps of its plain graph readers reader by reader, and leaves each asset with a gap out of the assets that the optimisation can trade. The last methods say whether a prior of the library gives no loadings, and record the source of the prior in the Prior Result that the prior fits. The public page documents the method that gives the source of each prior of the library.

AbstractPriorEstimator method of reader_frames: the frames that a prior adds to the group of its optimiser.

A prior is an outermost reader of the returns data, and at x_src = nothing it reads the raw returns rd.X. PortfolioOptimisers.plain_graph_reader — Function
plain_graph_reader(x) -> Bool

Answer whether x reads the returns matrix with a plain moment estimator, which refuses a gap in the matrix.

A graph reader, a clustering, network, phylogeny or centrality estimator, computes the correlation of the returns matrix with its ce. gap_fill_value on ce states what the estimator does with a gap. A finite answer marks a plain estimator, which refuses a gapped sample. NaN marks a mask-aware estimator, which reads the observed cells. A FeatureDistance reads the features of an Asset Panel and not the returns matrix, so a reader that holds one is not plain. A precomputed result reads nothing.

Algorithm

The method that Julia selects is the algorithm.

  1. A Tuple or a vector: true when one of its entries is plain.
  2. A ClustersEstimator or a NetworkEstimator: true when gap_fill_value(x.ce) is finite, and false when x.de is a FeatureDistance.
  3. An estimator that holds a graph reader: forward to the reader that it holds.
  4. Every other value, a precomputed result and nothing among them: false.

Arguments

  • x: A graph reader, a Tuple or a vector of graph readers, or any other value.

Returns

  • flag::Bool: true when x reads the returns matrix with a plain moment estimator.

PortfolioOptimisers.graph_reader_mask — Function
graph_reader_mask(x, imsk::Option{<:BitVector}, pr::AbstractPriorResult,
                  rd::ReturnsResult, strict::Bool) -> Option{BitVector}

Compose the Investable Mask with the assets that the plain graph readers of a fit can read, at the entry of the fit.

A graph reader that reads the returns data meets each gap that a mask-aware prior filled in its own returns only, see scenario_fill. The ce of the reader decides what the gap is. A mask-aware ce reads the observed cells, so this function keeps the asset. A plain ce has no correct answer for a gapped sample. So this function drops each kept asset that holds a non-finite cell in the rows that the readers read, as a plain estimator over an Asset Panel leaves the asset out of its Coverage Universe. The asset then departs as a non-investable asset: investable_reduction announces it, the fit gives it a zero weight, and it is listed on the Non-Investable Axis.

The fit warns once, and the warning names the assets and the two remedies of graph_gap_remedy. Under strict = true the fit refuses the gap instead. A reader that states the prior as its source, x_src = PriorSource(), reads the returns of the prior, where a kept column is finite, so this function keeps every asset for it. Each reader states its own source, so graph_reader_gaps finds the gaps reader by reader.

Every fit that calls feature_readable_mask calls this function on the mask that it gives. A direct call of a graph verb has no entry of a fit, so it refuses the gap with assert_graph_readable.

Algorithm

  1. Find the assets that hold a non-finite cell in the rows that the plain readers of x read, with graph_reader_gaps. Return imsk when no plain reader reads the returns.
  2. Keep the assets that imsk keeps. Return imsk when none of them holds a gap.
  3. Refuse under strict. Otherwise warn, and return imsk with those assets dropped.

Arguments

  • x: A graph reader, or a Tuple or a vector of the graph readers of the fit.
  • imsk: The Investable Mask of the prior, or nothing when every asset is investable.
  • pr: The prior result of the fit, on the full asset universe.
  • rd: The returns result to use.
  • strict: The strict field of the optimiser. true refuses a gap in place of the warning.

Validation

  • Under strict = true, no kept asset holds a non-finite cell in X. Raises an IsNonFiniteError.
  • At least one asset stays. Raises an IsEmptyError.

Returns

  • imsk::Option{BitVector}: The composed mask, or nothing when every asset stays.

PortfolioOptimisers.implied_volatility_picker — Function
implied_volatility_picker(
    pr::Union{AbstractPriorResult, ReturnsResult},
    X::AbstractMatrix{<:Union{Number, AbstractJuMPScalar}},
    iv::Union{Nothing, AbstractMatrix{<:Union{Number, AbstractJuMPScalar}}}
) -> Any

Pick the rows of the implied volatility matrix iv that pair the rows of the returns matrix X that returns_matrix_picker picked.

An ImpliedVolatility estimator pairs row t of iv with row t of X. The returns data carries iv, one row per observation of rd.X. A prior result can carry fewer rows in X than the returns data: a Scenario Cap keeps the last rows, and a CrossSectionalFactorPrior also drops the rows of the Descriptor warm-up and of the exposure lag. Each of them drops leading rows. A prior also drops the observations of a Shared Series gap, which are not leading rows, and it records them in pr.ss_gaps. So when iv is the implied volatility of the returns data that the prior read, the rows of pr.X are the last observations that the marks keep. An optimiser drops the same observations from the returns data before its readers read it, so inside an optimiser iv has fewer rows than the marks, and the last rows of iv pair the rows of pr.X. prior_data_rows tells the two cases apart. scenario_rows reads the probabilities w of a prior result on the last rows of the matrix that the prior fitted.

Algorithm

  1. Return iv unchanged when it is nothing, or when it has no more rows than X. A iv with fewer rows than X pairs no row, and the estimator that reads it refuses it.
  2. Otherwise return a view of the rows of iv that prior_data_rows pairs with the size(X, 1) rows of X.

Arguments

  • pr: The prior result or the returns data that the graph verb received. Only a prior result records the observations of a Shared Series gap.
  • X: The returns matrix that returns_matrix_picker picked, observations × assets.
  • iv: The implied volatility matrix of the returns data, observations × assets, or nothing.

Returns

  • iv::Option{<:MatNum}: The rows of iv that pair the rows of X, or nothing.
