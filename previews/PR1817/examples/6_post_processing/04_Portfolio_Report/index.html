Portfolio report

portfolio_report puts several predictions into one report. The report has an overview table with one row for each portfolio, and one entry for each prediction with its statistics, its weights and its figures. An entry also shows a finite allocation when you give one. write_report writes the report as Markdown, or as one HTML file that holds its style, its script and its figures. The HTML file opens in any browser with no network access.

This page builds one report from the three kinds of prediction:

  1. the best candidates of a grid search, each one predicted over a walk-forward path,
  2. a population of paths from a combinatorial cross-validation,
  3. one prediction on the last month, with a finite allocation of whole shares.
When to reach for this

Reach for a report when you want to compare many predictions side by side, or to give the results to someone who does not run Julia. Each figure and each statistic of the report comes from a function of the library, so a report shows nothing that you cannot compute yourself. Use performance_summary when you want the numbers alone.

5. The report

portfolio_report takes the predictions as one vector and their names. The keywords that it does not use pass to performance_summary. We keep them in ps_kw: ppy annualises the daily figures, rf is the risk-free rate of one day, and measures adds two risk measures by name. groups labels each prediction, and the HTML file shows or hides the portfolios of each group. allocs gives the finite allocation of each prediction, or nothing.

default_report_figures gives the default figures when GraphRecipes and StatsPlots are loaded: overview draws every prediction on one figure, and entry draws one prediction. A figure of your own is a pair caption => f. An entry figure calls f(pred), and a function that returns nothing adds no figure. Here the turnover figure draws a walk-forward path and skips the other two kinds of prediction.

turnover_figure(p::MultiPeriodPredictionResult) = plot_turnover(p)turnover_figure(::Any) = nothingfigs = default_report_figures()preds = [cands; ppred; pred]labels = ["search rank 1", "search rank 2", "search rank 3", "best, all paths",          "best, last month"]ps_kw = (; ppy = 252, rf = rf,         measures = [:cvar_95 => ConditionalValueatRisk(), :ulcer => UlcerIndex()])r = portfolio_report(preds; names = labels, title = "Minimum risk portfolios",                     groups = ["search", "search", "search", "population", "single fold"],                     allocs = [nothing, nothing, nothing, nothing, alloc],                     overview_figures = figs.overview,                     entry_figures = [figs.entry; "Turnover" => turnover_figure], ps_kw...);
