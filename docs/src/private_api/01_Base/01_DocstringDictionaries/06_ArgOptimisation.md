# Optimisation arguments: private API

This file defines no name. It fills [`arg_dict`](@ref) with the descriptions of the optimisers, the solvers and the JuMP models, their results, cross-validation, prediction, allocation and the online step. [`unique_key_dict!`](@ref) refuses a key that another entry holds with a different description.
