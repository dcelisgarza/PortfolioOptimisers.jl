# [Data and moment notation: private API](@id private-api-data-and-moment-notation)

This file defines no name. It fills [`math_dict`](@ref) with the notation of the data, the returns and their moments, the distances, the feature matrices, denoising, the norm errors, the Gerber family and the calibration rules. [`unique_key_dict!`](@ref) refuses a key that another entry holds with a different description.
