# Data and moment arguments: private API

This file defines no name. It fills [`arg_dict`](@ref) with the descriptions of the data, the moments and the matrices estimated from them, the regime-adjusted and exponentially weighted estimators, and the partial fit states. [`unique_key_dict!`](@ref) refuses a key that another entry holds with a different description.
