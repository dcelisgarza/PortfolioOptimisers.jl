# Validation and return descriptions: private API

This file defines no name. It fills [`val_dict`](@ref) with the `# Validation` rules, and it also fills [`ret_dict`](@ref) with the `# Returns` descriptions and [`err_name_dict`](@ref) with the nouns of the error messages. [`unique_key_dict!`](@ref) refuses a key that another entry holds with a different description.
