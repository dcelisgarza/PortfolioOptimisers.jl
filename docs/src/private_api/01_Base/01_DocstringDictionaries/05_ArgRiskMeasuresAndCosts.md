# Risk measure and cost arguments: private API

This file defines no name. It fills [`arg_dict`](@ref) with the descriptions of the risk measures and their settings, the return terms, tracking, turnover, fees and trading costs. [`unique_key_dict!`](@ref) refuses a key that another entry holds with a different description.
