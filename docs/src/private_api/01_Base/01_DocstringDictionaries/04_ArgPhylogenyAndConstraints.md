# Phylogeny and constraint arguments: private API

This file defines no name. It fills [`arg_dict`](@ref) with the descriptions of phylogeny and clustering, the universe sets, the constraints and their generation, the weight bounds and preselection. [`unique_key_dict!`](@ref) refuses a key that another entry holds with a different description.
