# Prior and uncertainty set arguments: private API

This file defines no name. It fills [`arg_dict`](@ref) with the descriptions of the priors and their results, the entropy pooling, Black-Litterman and opinion pooling views, the higher order priors and the uncertainty sets. [`unique_key_dict!`](@ref) refuses a key that another entry holds with a different description.
